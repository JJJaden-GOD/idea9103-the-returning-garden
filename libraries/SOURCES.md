# Included libraries

These are unmodified distribution files, loaded locally by `index.html`.

- `p5.min.js`: p5.js 1.11.11, from https://cdn.jsdelivr.net/npm/p5@1.11.11/lib/p5.min.js
- `p5.sound.min.js`: the sound add-on distributed in the same p5 package, from https://cdn.jsdelivr.net/npm/p5@1.11.11/lib/addons/p5.sound.min.js
- `p5-license.txt`: the p5.js LGPL 2.1 licence, retained from the package.
- `p5-sound-license.txt`: p5.sound's MIT licence, from https://github.com/processing/p5.js-sound/blob/main/LICENSE

Official project sources: https://github.com/processing/p5.js and https://github.com/processing/p5.js-sound

The bundled p5.sound file has its own historical version banner. Its version is separate from the containing p5.js package's version number.
